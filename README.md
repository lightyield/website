## 2. ローカルでの動作確認手順

静的ファイルのみで構成されているため、ローカルの簡易HTTPサーバー等で手軽にプレビュー可能です。

```bash
# Pythonを使用する場合
python3 -m http.server 8000

# または npx serve を使用する場合
npx serve .
```

ブラウザで `http://localhost:8000`（または指定ポート）を開いて確認してください。

## 3. ブログ記事の追加手順

新しいブログ・知見記事を追加する際は、以下の手順でファイルを配置・更新します。

1. **記事フォルダの作成**:
   該当カテゴリのディレクトリ配下に `YYYYMMDD-<article-slug>` 形式で作成します。
   - WBSで覗いてみた: `blog/peek-into-wbs/YYYYMMDD-<slug>/`（例: `blog/peek-into-wbs/20261009-kindle-wbs/`）
   - 知見・コラム: `blog/knowledge-column/YYYYMMDD-<slug>/`（例: `blog/knowledge-column/20261010-digital-agency-wbs/`）
2. **画像・HTMLファイルの作成**:
   - `images/` サブディレクトリに記事内で使用する画像を配置（命名規則: `<slug>_fig1_xxx.jpg` 等のプレフィックス推奨）。
   - `index.html` を作成（既存の類似記事の `index.html` をテンプレートとして活用。CSS/JSの相対パスは `../../../css/`、`../../../js/`。関連記事への誘導リンク等は冒頭ではなく末尾の「終わりに」セクションに配置）。
3. **ブログ一覧・トップページへの追加**:
   - `blog/index.html` の `.blog_grid` 内に新しい記事カードを追加（全記事を掲載）。
   - トップページ（`index.html`）の `.blog_grid` 内を更新。**トップページは各カテゴリ新着2件のみ表示**するため、新着記事を追加した際は3件目となる最古の記事カードを削除してください。
4. **前後の記事ナビゲーション（`article_pager`）の更新**:
   - 追加した新記事の `index.html` 内の `.article_pager` に、同カテゴリ内の直前の過去記事へのリンク（`pager_prev`）を設定します。
   - 直前の記事（これまで最新だった記事）の `index.html` を開き、新記事へのリンク（`pager_next`）を追加・更新します。

## 4. デザイン仕様（トップページ ヒーローセクション）

トップページのヒーローセクション（ファーストビュー）には、ブランドの洗練された世界観と空間深度を演出する幾何学ポリゴンリング（Broken Ring）がインラインSVGとして配置されています。

- **デザイン特徴**:
  - スイス・スタイルの巨匠ヨゼフ・ミューラー＝ブロックマン（Josef Müller-Brockmann）の幾何学的拡大構造（中心から外側に向かってブロックが滑らかに厚みを増すイージング設計）を幾何学ポリゴンリングに融合したデザイン。
  - コーポレートカラー（ライトブルー〜ディープネイビー）と調和するグラデーションおよびダークトーンの背景レイアウト。
- **完全スタンドアロン設計（外部依存ゼロ）**:
  - 外部ライブラリ（JavaScriptやCanvas）、外部画像リクエスト（CDN等）を一切使用せず、`index.html` 内に最適化された軽量インラインSVGコードとして直接埋め込まれています。
  - 外部サービスの稼働状況や将来のサイト閉鎖等に左右されず、高速かつ永久に安定して描画されます。
- **著作権・商用利用フリー**:
  - アルゴリズムにより数学的計算から完全新規生成された独自SVGデータであり、商用利用を含め権利上の制約なく安全に利用可能です。
- **レスポンシブ対応**:
  - PC・タブレット・スマートフォン（`@media (max-width: 768px)`）の各画面幅において、コピー（文字）の視認性を最優先し、テキストと重なりすぎないよう透過度（opacity）と配置位置がCSS（`css/base.css`）で調整されています。

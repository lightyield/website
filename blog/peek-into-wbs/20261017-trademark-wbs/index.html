社名・ロゴの商標登録出願を行うWBSを作ってみた

今回は「WBSで覗いてみた」シリーズとして、「社名・ロゴの商標登録出願を行うWBS」を作成しました。

自社の社名やブランドロゴ、サービス名を特許庁に商標登録することは、第三者による無断使用や模倣を防ぎ、自社の信用と事業活動を法的に保護するために重要な手続きです。

一般的には弁理士などの専門家に依頼することも多い手続きですが、特許庁が公開している審査基準や電子出願システムを活用することで、自社内で直接手続きを進めることも可能です。

そこで今回は、株式会社ライトイールドの実際の社名およびコーポレートロゴを題材とし、先行調査から願書作成、特許庁の審査、設定登録料の納付、そして商標権発生に至る全工程をWBSに分解し、タスクの依存関係や所要期間、費用構造について淡々と検証していきます。

※そもそも「WBSとは何か？」「平準化とは何か？」について詳しく知りたい方は、こちらの記事「WBSの勘所」や「ガントチャートの決め手は平準化」も合わせてご覧ください。

1. 出願対象の商標と前提条件

まずは、今回出願の対象とする商標と、プロジェクトの前提条件を整理します。

商標法上、出願対象には文字のみを指定する「文字商標」と、マークや図形を含む「図形商標・結合商標」が存在します。今回は、ライトイールドの社名およびコーポレートロゴを題材とします。

図1は、シンボルマークと英字表記「LIGHT YIELD」、日本語表記「株式会社ライトイールド」を組み合わせたロゴです。実際の出願にあたっては、文字商標として「ライトイールド」「lightyield」を登録する形態と、ロゴ画像そのものを登録する形態が考えられます。

本WBSでは、以下の体制と条件を前提としてモデル化しました。

  • 実施体制: 出願人（自分1名体制）＋ 特許庁審査官（外部リソース）。弁理士等を介さず、特許庁のWEB申請システムによる電子出願を自社で直接行う想定とします。
  • 指定区分・役務: ライトイールドの主たる事業領域である「第42類（ソフトウェア開発・クラウド環境構築・IT技術提供）」の1区分を対象とします。
  • 審査方式: 既にWebサイトや事業活動で使用している商標であることを証明し、「早期審査制度」を活用して審査待ち期間を短縮するルートを想定します。
  • 登録期間: 登録査定後の設定登録料は、10年分を一括納付する標準設定とします。

2. WBSを作成する（全体工程とクリティカルパス）

前提条件をもとに、先行調査から商標原簿登録までの全作業を洗い出し、タスク間の依存関係（FS関係）とリソースを定義したガントチャートを作成しました。

図2のガントチャートから、全体の工程とタイムラインの特徴が把握できます。

プロジェクト全体の所要期間は「64日4時間（実日数で約3ヶ月強）」となっています。このうち、自分自身が手を動かす実作業の工数は合計で「4日2時間（34時間）」程度にとどまります。

スケジュールの大部分（約50営業日＝約2ヶ月強）は、特許庁による審査待ち時間（外部リードタイム）が占めています。このように、「作業者の工数」と「外部の待機期間」が明確に分離されている点が、官公庁手続き系プロジェクトの典型的な特徴です。

また、全体の進捗を客観的に管理できるよう、各フェーズの節目に完了マイルストーン（先行調査完了、願書作成完了、出願完了、特許庁審査完了、商標権発生完了）を設定しています。

3. 各工程の詳細とタスクのポイント

WBSを構成する5つのグループタスクについて、具体的な作業内容と実務上の留意点を順に見ていきます。

1. 先行調査・要件定義（所要: 2日 / 工数: 16時間）

商標出願において最も手戻りのリスクが高く、慎重な検討が求められるフェーズです。

  • 出願商標の仕様確定（4h）: 文字商標（標準文字）とするか、ロゴ（図形商標）とするか、あるいは両方とするかなど、権利化する外観や構成を確定します。
  • 事業棚卸し・区分選定（4h）: 自社の現行サービスおよび今後展開予定の事業内容を棚卸しし、全45区分の中から権利を保護すべき区分を絞り込みます（今回は第42類）。
  • 指定商品・役務の標準名称抽出（4h）: 特許庁の「類似商品・役務審査基準」に掲載されている公式の標準名称を採用します。独自の説明文を記述すると、区分不明瞭として拒絶理由通知の対象になりやすいため、標準名称を活用することが安全です。
  • J-PlatPatスクリーニング調査（4h）: 特許庁の特許情報プラットフォーム（J-PlatPat）を用い、対象区分および類似群コードにおいて、同一または類似する先願・登録商標が存在しないかを徹底的に検索・照合します。

2. 出願準備・願書作成（所要: 1日2時間 / 工数: 10時間 / 費用: 12,000円）

先行調査で競合商標がないことを確認した後、正式な願書の作成と手数料の準備に進みます。

  • 出願方式決定＆環境準備（4h）: 書面（紙）による出願は書面電子化手数料（1件につき数千円）が別途発生するため、オンラインで完結する「WEB申請（電子出願）」を選択し、特許庁アカウントや認証環境を整備します。
  • 商標登録願ドラフト作成（4h）: 特許庁所定の書式に従い、出願人の名称・住所、商標見本、区分および指定役務を正確に記述します。
  • 出願手数料の計算・納付準備（2h / 12,000円）: 1区分あたりの法定出願料（3,400円 ＋ 8,600円×1 ＝ 12,000円）の納付手続き（電子納付）を準備します。

3. 出願手続き（所要: 1日 / 工数: 8時間）

特許庁システムへの送信と、審査期間短縮のための申請を行います。

  • 出願実行（4h）: WEB申請システムを通じて願書データを特許庁へ正式送信し、電子納付を完了させ、出願番号を受領します。
  • （任意）早期審査事情説明書の提出（4h）: 自社で既に使用している商標（Webサイトやパンフレット等）の証拠資料を添えて「早期審査事情説明書」を提出します。これにより、通常約5〜8ヶ月かかる実体審査を約2ヶ月前後に短縮することが可能です。

4. 特許庁審査（所要: 50営業日 / 工数: 0時間）

特許庁側による審査期間です。出願人側の作業は発生せず、結果の通知を待つフェーズとなります。

  • 方式審査（特許庁 約10営業日・2週間）: 願書の形式的要件、印紙額、記載事項の不備がないかを特許庁がチェックします。
  • 実体審査（特許庁 約40営業日・約8週間）: 審査官が識別力（一般的な名称でないか等）や他者の既存登録との類似性を実質的に審査します。問題がなければ「登録査定」が通知されます。

5. 登録査定・商標権発生（所要: 10日2時間 / 工数: 2時間 / 費用: 32,900円）

審査を通過した後、登録料を納付して商標権を正式に発生させる最終工程です。

  • 設定登録料の納付手続き（2h / 32,900円）: 登録査定の謄本送達から30日以内に、特許庁へ10年分の設定登録料（1区分あたり32,900円）を納付します。
  • 商標原簿登録・商標権発生（特許庁 約10営業日・2週間）: 特許庁の商標原簿に正式に登録され、日本全国における排他的・独占的な商標権が発生します。後日、特許庁より商標登録証が送付され、全工程が完了します。

4. プロジェクトにかかる費用構造

本WBSにおける費用の構造について整理します。

外部の専門家（弁理士）を介さず自社で直接手続きを行う場合、発生する金銭的コストは特許庁への「法定費用（特許印紙代）」のみとなります。

費目 内訳・根拠 金額
出願手数料（特許庁印紙代） 1区分（基本料3,400円 ＋ 8,600円×1区分） 12,000円
設定登録料（特許庁印紙代） 1区分・10年一括納付（32,900円×1区分） 32,900円
専門家報酬（代理人手数料） 自社による直接出願（外部委託なし） 0円
合計法定費用 1区分・10年間有効 44,900円

一般的に弁理士や特許事務所へ依頼した場合は、事前調査手数料、出願手数料、登録成功報酬などが加算され、1区分あたり概ね15万円〜22万円程度の総額となることが一般的です。

自社で手続きを行うことで金銭的な支出を法定実費の44,900円のみに抑えられる一方、出願商標の仕様確定や指定役務の標準名称選定、先行調査などに約34時間（約4.25人日）の社内リソースを投入することになります。自社の稼働状況や調査・書類作成の負担と、外部費用の削減幅を比較して方針を選択することが合理的です。

終わりに

今回は、自社の社名およびロゴマークを題材に、特許庁への商標登録出願プロジェクトをWBSに分解しました。

商標登録は法的な手続きであるため難解な印象を持たれやすいですが、作業を分解してみると、出願人側が対応すべき実作業は「調査」「願書作成」「納付」の約34時間程度であり、全体工程の大半は特許庁の審査待ち時間であることが明確になります。

区分や指定役務を特許庁の公式な標準名称から選定しておくこと、そして事前調査を適切に行うことで、手戻り（拒絶理由通知への対応）を防ぎ、スムーズな権利化を進めることが可能です。

社名やブランドロゴの権利保護を検討する際の参考になれば幸いです。

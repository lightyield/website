ガントチャートの決め手は平準化

INDEX 目次

  2. 2. ガントチャートの平準化が行うこと
  3. 3. 平準化はいつ、何のために使うのか

  5. 5. 平準化が使えるガントチャートツール

「ガントチャートツールってどれを選べば良いの？」と聞かれたら、私は迷わず「平準化ができること」と答えます。「平準化とは何か」「なぜそれほど重要なのか」が気になっている方に向けて、今回は平準化の基本的な意味やそのメリットについて解説します。

※そもそもWBS（作業分解構造）について詳しく知りたい方は、こちらの記事「WBSの勘所」も合わせてご覧ください。

1. 平準化とは

以下は、ITmedia情報マネジメント用語辞典における平準化の定義です。

需要や業務負荷などが特定の時期や資源に集中しているといった偏りを排し、均等に配分すること。
（中略）
プロジェクトマネジメントなどでは、プロジェクトの計画段階で特定の人員にタスクが集中してしまうことがあるが、このままでは実施不可能である。そこでリソースヒストグラムを利用して、作業の平準化を行う。
（ITmedia情報マネジメント用語辞典より）

幅広い分野で使われる言葉ですが、本記事で解説するガントチャートにおける平準化とは、「プロジェクトメンバーの作業負荷を均等にならすこと」を指します。

2. ガントチャートの平準化が行うこと

ガントチャートツールの平準化とは一体どんな機能なのか。まずは平準化を行う前後のガントチャートをご覧ください。

平準化を行うことで、メンバーの作業がならされたのが分かります。これは予め設定された1日の作業上限時間を超えたためであり、コンピューターがメンバーに対する1日あたりの作業負荷を分散しつつ、プロジェクト期間が長くなるように自動調整しています。

つまり、平準化とはメンバーの負荷を考慮しながら、プロジェクト期間をより現実的なスケジュールに調整してくれる機能です。

3. 平準化はいつ、何のために使うのか

平準化を実施するタイミングは「随時（いつでも）」です。ガントチャートに作業を追加・変更・削除した際など、計画に変化が生じた時は常に平準化を行います。また、平準化を行う最大の目的は「未来を予測するため」です。

私はガントチャートツールを「コンピューターに未来を予測してもらうツール」と捉えています。コンピューターに計算させることで、この先のスケジュールを客観的に捉えるようにしています。自分でガントチャートを作成した場合、どうしても自分の感覚や守備範囲でしか計算が行われません。特に期待値を含む個人的な感情で優先順位が決まりがちになり、結果として実態と乖離した精度の低いスケジュールになってしまいます。

平準化機能のないツールで計画を立てると、自分が頭に描いた通りの都合の良いスケジュールにしかなりません。自分の考え方が正しいことを前提とした「見た目が綺麗なガントチャート」が生まれるだけであり、現実的な未来予測とは言えなくなってしまいます。

4. 平準化を使うメリット

先述の通り、平準化を使うメリットは「コンピューターによる客観的な計算」にあります。人間が手作業で考えるのではなく、コンピューターに計算を任せることで、何度でも繰り返しシミュレーションを行うことができます。時には予想と全く異なる計算結果が出ることもありますが、設定された前提条件（パラメータ）に誤りがなければ、それこそが論理的に導き出された現実的な計画です。

平準化を敬遠する人の多くは、この「自分の予想と違う結果が出ること（思い通りにならないこと）」を嫌います。しかし、私は自分の感覚を過信するのではなく、コンピューターが算出した客観的な結果を選択肢の一つとして真摯に検討すべきだと考えています。

実際、私がスケジュールを計画する際は、パラメータの設定に最も多くの時間を使います。そして、そのパラメータに基づきコンピューターが計算した結果を採用するようにしています。もちろん採用に至るまではシミュレーションを何度も繰り返し、プロジェクトのQCD（品質・コスト・納期）のバランスが最も優れた計画を模索します。

5. 平準化が使えるガントチャートツール

世の中には数多くのガントチャートツールが存在しますが、平準化機能を備えたツールは意外と多くありません。私が知る限りでは主に以下の2つであり、利用するOSによって選択肢が分かれます。

Microsoft Project

Microsoft Project 公式サイト

言わずと知れたガントチャートの王道ツールです。私自身このツールを長く愛用しており、10年以上にわたり活用してきました。多彩なパラメータに基づく平準化アルゴリズムは非常に高度で、未来予測のシミュレーションを行うには最適です。クラウド版やデスクトップ版など多彩な展開がありますが、平準化機能は主にデスクトップ版（Windows環境）で強力に動作します。

OmniPlan

OmniPlan 公式サイト

Macユーザー向けの代表的なガントチャートツールです。洗練されたUIを備えており、直感的な操作が可能です。Standard版でも平準化機能が標準搭載されているため、コストパフォーマンスにも優れています。macOS環境で本格的なスケジュールシミュレーションを行いたい場合の有力な選択肢となります。

終わりに

ガントチャートツールは単にスケジュールを管理するだけでなく、「未来を客観的に予測するツール」です。そう捉えることで、ガントチャートに対する向き合い方も変わってくるのではないでしょうか。

私はWBSに変更があればすぐさまガントチャートツールを走らせ、今後のスケジュールを再計算します。当初計画の変更を嫌う傾向もありますが、プロジェクト管理の本質とは「過去の計画に固執するのではなく、現在の状況を正確に把握し、未来を客観的に予測し続けること」だと考えています。

今回の記事が、平準化を活用したことのない方やプロジェクト管理に悩む方にとって参考になれば幸いです。また、プロジェクト計画の基本となるWBSの作成方法については「WBSの勘所」も合わせてご覧ください。
